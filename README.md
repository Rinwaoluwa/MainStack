# Revenue Dashboard - Production-Ready React Application

A senior-level React dashboard application built with Vite, TypeScript, and Framer Motion. This project demonstrates best practices in component architecture, accessibility, performance optimization, and comprehensive testing.

## Features

- **Modern React Stack**: Vite + React 18 + TypeScript with strict mode
- **Responsive Design**: Mobile-first approach with full responsiveness
- **Smooth Animations**: Framer Motion with spring physics and micro-interactions
- **Accessibility First**: WCAG compliant with keyboard navigation and ARIA attributes
- **Comprehensive Testing**: 80%+ coverage with Vitest + React Testing Library
- **Design System**: Centralized design tokens with CSS variables
- **Production Ready**: Optimized bundle, lazy loading, and performance monitoring

## Getting Started

### Prerequisites

- Node.js 16+ and npm/yarn
- Basic knowledge of React and TypeScript

### Installation

1. Clone the repository:
\`\`\`bash
git clone <repository-url>
cd revenue-dashboard
\`\`\`

2. Install dependencies:
\`\`\`bash
npm install
\`\`\`

3. Start the development server:
\`\`\`bash
npm run dev
\`\`\`

The application will be available at `http://localhost:5173`

# Development server
